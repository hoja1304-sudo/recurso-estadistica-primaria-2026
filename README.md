# Estadística: conceptos, medidas de posición y variabilidad

Recurso interactivo de Matemática — **Primaria 2026 (Costa Rica)**.

**Bloque 5. Estadística y Probabilidades** · Corresponde a los ítems 54, 55 y 56.

Reconoce los conceptos de **población y muestra**, calcula **medidas de posición** (moda, media aritmética, mínimo y máximo) y el **recorrido** (variabilidad) de un grupo de datos.

## Contenido

- **Teoría** con tres temas (población y muestra · medidas de posición · recorrido) y ejemplos interactivos.
- **Práctica** con tres ejercicios de selección única, retroalimentación paso a paso y práctica ilimitada con valores aleatorios.

Es un único archivo HTML autocontenido (sin dependencias externas). Se abre directamente en cualquier navegador.
